# Online Feedback Collector

A web-based feedback collection system built using Flask, Python, SQLite, HTML, CSS, and JavaScript.

## Features

- User feedback submission
- Star rating system
- SQLite database storage
- Admin login authentication
- Admin dashboard
- View submitted feedback
- Search feedback by name, email, or comments
- Filter feedback by rating
- Delete feedback
- Average rating calculation
- Total feedback statistics
- Five-star feedback statistics
- Admin logout

## Technologies Used

- Python
- Flask
- SQLite
- HTML5
- CSS3
- JavaScript
- Jinja2
